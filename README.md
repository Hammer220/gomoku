## ✨ 功能概览

### 🎮 游戏核心
- 标准 15×15 棋盘，Canvas 绘制，支持高 DPI
- 径向渐变棋子（黑棋/白棋高光），带阴影效果
- 胜负判定（四方向五连检测），平局检测，胜利高亮
- 悔棋功能（每局最多 3 次），游戏计时
- 响应式棋盘，窗口缩放自动重绘

### 🤖 AI 对战
- 三种难度：简单、中等、困难
- 活三检测，禁手规避（三三、四四、长连）
- 对局中可随时切换难度

### 👥 双人对战
- 同机双人轮流落子
- 禁手规则开关，单步计时（超时判负）

### 🌐 联机对战
- 创建/加入房间，房间大厅实时列表
- 实时轮询同步（0.8 秒刷新）
- 断线重连，心跳保活，服务器重启恢复
- 重新开始，关闭房间，离开房间

### 👤 用户系统
- 注册/登录（极验验证码），SHA256 密码哈希
- 个人资料，修改密码
- Token 持久化（localStorage），封禁检测

### 🛡️ 管理员后台
- 用户列表管理（搜索、分页、封禁、解封、修改积分/密码）
- 批量操作（批量封禁/解封/登出）
- 平台统计，全部记录查看与导出

### 👑 超级管理员专属
- 创建普通管理员，管理管理员权限
- 联机对局实时监控，强制落子，强制关闭房间
- 棋盘颜色设置

### 🎨 棋盘外观定制
- 线条颜色、星位点颜色自定义
- 多背景图片切换，自定义背景上传
- 设置持久化（保存到服务器）

### 📊 数据统计与记录
- 个人统计（对局数、胜场、胜率）
- 历史记录（最近 50 条，支持筛选分页）
- 积分系统（难度差异化积分）
- 排行榜（全服前 50 名）

### 🔄 棋谱复盘
- 逐步播放，自动播放，速度调节
- 棋谱列表，当前步高亮

### 💾 存档系统

## 🚀 快速开始（三步跑起来）

### 1️⃣ 克隆仓库

```bash
git clone https://gitee.com/Guoguo220/public1.git
cd gomoku
```

### 2️⃣ 安装依赖

```bash
pip install flask
```

> 仅需 Flask，无需数据库，所有数据存储在 `data/` 文件夹（JSON 格式）

### 3️⃣ 启动服务器

```bash
python3 app.py
```

终端会输出：

```
管理员账号: admin
管理员密码: "随机生成"
服务器启动: http://localhost:8000
```

> 超级管理员 `admin` 的**随机密码**保存在 `data/password.json`，第一次启动自动生成。

打开浏览器访问 `http://localhost:8000`，开始你的棋局！

## 🎯 核心玩法介绍

### 🧠 人机对战

- **简单**：优先赢棋 → 堵对方 → 堵活三 → 中心加权随机，适合新手
- **中等**：位置评估函数，综合进攻 + 防守，会堵你活四
- **困难**：深度评估局面，模拟对手最优应对，攻守兼备

### 👥 双人对战

- 同一台设备两人轮流落子，适合面对面切磋
- 可开启禁手规则（三三、四四、长连）
- 可设置单步时间限制，超时判负

### 🌐 联机对战（重点）

1. 点击「联机对战」→「创建房间」→ 把房间号发给朋友
2. 朋友在「输入房间号」加入，系统随机分配黑白棋
3. **实时轮询同步**：每一步、对局状态、胜利 / 平局实时更新
4. 创建者可「重新开始」或「关闭房间」
5. 离开房间后可随时查看大厅其他可加入房间
6. 断线后刷新页面自动恢复对局

### 🧑‍💼 管理员能力

- 查看所有用户**积分、胜场、明文密码、在线状态**
- 封禁用户、解封、强制登出，修改任意用户的密码、积分
- 超级管理员可创建普通管理员，管理管理员权限
- 联机对局实时监控（查看房间、强制落子、强制关闭房间）

## 🔧 技术栈

| 技术                | 用途                              |
| ----------------- | ------------------------------- |
| **Flask**         | 轻量级后端，提供 REST API               |
| **原生 JavaScript** | 前端无框架，命名空间模块化，性能优越            |
| **Canvas 绘制**     | 棋盘 / 棋子 / 渐变 / 阴影 / 高亮动画        |
| **文件系统 + 锁**      | 无数据库，JSON 存储 + 线程锁保证数据安全        |
| **内存缓存**          | 用户信息、token 30 秒缓存，大幅减少磁盘 IO     |
| **轮询机制**          | 联机状态 0.8 秒刷新，指数退避重试，保证实时性      |
| **SHA256 哈希**      | 密码加密存储，明文密码仅管理员可见              |
| **极验验证码**         | 注册/登录人机验证，防止机器人                |
| **响应式布局**         | TailwindCSS + ResizeObserver 自适应画布  |

## 💡 细腻设计细节

- **悔棋限制**：每局最多 3 次，避免滥用。AI 模式下悔两步（自己+AI），PVP 悔一步
- **禁手规则**：支持三三禁手、四四禁手、长连禁手，AI 自动遵守，PVP 模式可选开关
- **胜利高亮**：连成五子时，那五颗棋子以金色虚线高亮闪烁
- **棋子渐变**：黑棋高光到暗部，白棋高光到暗部，带阴影，视觉效果逼真
- **超时清理**：联机房间创建超 2 小时或关闭超 1 小时自动清理
- **自动端口切换**：8000 被占用时自动尝试 8001~8010
- **跨平台**：Windows / macOS / Linux 均测试通过
- **离线存储**：登录 token 保存在 localStorage，刷新页面不用重新登录
- **断线判负**：玩家连接断开超过 120s 或心跳超时即判对手获胜，不再提供宽限期
- **服务器重启恢复**：重启后进行中的房间自动回到 waiting 状态等待双方重新加入
- **数据备份**：写入失败时自动创建 .bak 备份文件
- **防抖搜索**：用户搜索 300ms 防抖，减少不必要的请求
- **高 DPI 适配**：监控棋盘支持 Retina 显示屏，像素比自动适配

## ❓ 常见问题

**Q：忘记 admin 密码怎么办？**\
A：删除 `data/` 文件夹，重启 `app.py` 会自动重新生成随机密码，并打印在终端。

**Q：普通管理员被封禁权限后还能做什么？**\
A：可以正常游戏、修改自己的资料，但无法打开管理后台，也无法进行任何管理操作。

**Q：联机对战有房间列表上限吗？**\
A：无上限，创建的房间会一直保存直到手动关闭或超时清理。

**Q：棋盘背景图怎么换？**\
A：在管理后台的"棋盘外观"面板中，可以直接上传自定义背景图片，或从 `picture/` 目录加载预设背景。

**Q：数据会丢失吗？**\
A：所有数据以 JSON 形式持久化到硬盘，正常关闭服务器不丢失。写入失败时会自动创建备份。建议定期备份 `data/` 文件夹。

**Q：免密登录怎么用？**\
A：管理员可为指定用户开启免密登录，并设置最大次数（0=无限制）。用户开启后，在登录页面输入用户名即可免密登录。

**Q：AI 难度有什么区别？**\
A：简单=优先赢棋+堵活三+随机；中等=位置评估+攻守平衡；困难=深度搜索+模拟对手最优应对。
