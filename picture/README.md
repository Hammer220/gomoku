# 五子棋棋盘背景图片说明

## 图片规格

### 基础规范

- **文件格式**：支持 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`
- **推荐尺寸**：500×500 像素或更大（正方形）
- **文件大小**：建议不超过 500KB
- **分辨率**：72-150 DPI

### 内容要求

**图片仅需包含纯粹的纹理/底色，不需要任何棋盘元素。**

| 元素 | 是否需要 | 说明 |
|------|---------|------|
| 网格线 | ❌ 不需要 | CSS `linear-gradient` 动态生成 |
| 星位点 | ❌ 不需要 | Canvas 动态绘制 |
| 棋子 | ❌ 不需要 | Canvas 动态绘制 |

## 风格说明

### 传统风格
- **木纹**：温暖棕色调，自然木材纹理
- **布纹**：柔和米色，细腻织物质感
- **复古纸张**：泛黄米白色，纸张纤维纹理

### 自然风格
- **大理石**：灰色米色，自然纹理变化
- **水墨风格**：黑白灰为主，淡墨色调

### 现代风格
- **纯色渐变**：简洁干净，通用性强
- **抽象艺术**：几何图案，个性独特

### 科技风格
- **科技感**：深蓝深灰，青蓝色光效，赛博朋克风
- **科幻风格**：暗色调，荧光色点缀，神秘梦幻

## 用户上传图片

用户可以在游戏设置中上传自己的背景图片：

### 使用方法
1. 登录游戏后进入"设置"页面
2. 找到"棋盘颜色设置"区域
3. 点击"上传图片"按钮选择图片文件
4. 根据需要勾选"保存到服务器"选项
5. 图片会自动应用为棋盘背景

### 存储选项
- **保存到服务器**：图片会保存到服务器的 `picture` 文件夹，文件名格式为 `原文件名(用户名).扩展名`，所有用户都可以使用这些图片
- **不保存到服务器**：图片仅转换为 Base64 格式，仅当前用户当前会话可用，图片大小限制 500KB

### 上传要求
- 支持格式：`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`
- 推荐尺寸：500×500 像素或更大（正方形）
- 图片内容仅需包含纯粹的纹理/底色，不需要任何棋盘元素
