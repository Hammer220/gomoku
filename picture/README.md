# 五子棋棋盘背景图片说明

## 图片规格

### 基础规范

- **文件格式**：支持 `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`
- **推荐尺寸**：500×500 像素或更大（正方形）
- **文件大小**：建议不超过 500KB
- **分辨率**：72-150 DPI

### 内容要求

**图片仅需包含纯粹的纹理/底色，不需要任何棋盘元素。**

| 元素 | 是否需要 | 说明 |
|------|---------|------|
| 网格线 | ❌ 不需要 | CSS `linear-gradient` 动态生成 |
| 星位点 | ❌ 不需要 | Canvas 动态绘制 |
| 棋子 | ❌ 不需要 | Canvas 动态绘制 |

## 风格说明

### 传统风格
- **木纹**：温暖棕色调，自然木材纹理
- **布纹**：柔和米色，细腻织物质感
- **复古纸张**：泛黄米白色，纸张纤维纹理

### 自然风格
- **大理石**：灰色米色，自然纹理变化
- **水墨风格**：黑白灰为主，淡墨色调

### 现代风格
- **纯色渐变**：简洁干净，通用性强
- **抽象艺术**：几何图案，个性独特

### 科技风格
- **科技感**：深蓝深灰，青蓝色光效，赛博朋克风
- **科幻风格**：暗色调，荧光色点缀，神秘梦幻

## 添加新图片

将图片文件直接放入此目录即可，系统会自动识别并在管理面板中显示。

### 命名建议
- 使用简洁的中文或英文名称
- 示例：`星空.jpg`、`森林.jpg`、`极简.jpg`

## 最终显示效果

背景图片会被棋盘容器覆盖显示，代码自动叠加：

```
┌─────────────────────────────┐
│  [背景图片：任意风格纹理]     │
│                             │
│  ──┬──┬──┬──┬──┬──┬──┬──   │  ← CSS 网格线（可配置颜色）
│    │• │  │  │• │  │  │      │  ← Canvas 星位点
│  ──┼──┼──┼──┼──┼──┼──┼──   │
│    │  │● │  │  │  │  │      │  ← Canvas 棋子
│  ──┼──┼──┼──┼──┼──┼──┼──   │
│    │  │  │○ │  │  │  │      │
│  ──┴──┴──┴──┴──┴──┴──┴──   │
└─────────────────────────────┘
```
